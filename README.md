# Computer Vision Notebooks

Hands-on computer vision work in PyTorch and OpenCV, from fundamentals to two complete image-classification projects. Every notebook opens in Google Colab (badge at the top of each file).

## Projects
| Notebook | What it does | Result |
|---|---|---|
| [SkyVision_project](SkyVision_project.ipynb) | Weather image classifier — **Cloudy / Rain / Shine / Sunrise** — transfer learning on **ResNet-18** | **98% validation accuracy** |
| [menu_detector_model](menu_detector_model.ipynb) | Food classifier — hamburger, hot dog, dessert, kebab, **pilaf (osh)** — **MobileNetV2**, upload a photo and get predictions | ~94% validation accuracy |
| [data_scraping](data_scraping.ipynb) | Builds image datasets automatically with `bing-image-downloader` | — |

## Fundamentals
| Notebook | Topic |
